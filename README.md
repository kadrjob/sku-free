## Почему это нужно

Стандартный поиск 1С ищет вхождение подстроки. Если оператор написал чуть иначе — товара «нет»:

- «Болт М16 оцинкованный» и «Болт М16х60 оцинк. ГОСТ 7798-70» — разные позиции.
- «оцинк» вместо «оцинкованный» — не находит.
- «M16» латиницей вместо «М16» кириллицей — не находит.
- Пропущен пробел или другой падеж — не находит.

Результат: дубли номенклатуры, разъезжаются остатки, путаются цены.

SKU Search решает это: строит поисковый индекс и находит похожие товары даже с ошибками и сокращениями.

## Как подключить к 1С

Сервис общается по HTTP/JSON. В архиве идёт расширение `1c-extension/СКУПоиск.cfe`, которое можно подключить к УТ 11 / ERP / БП.

Минимальный код для интеграции:

```bsl
&НаСервере
Функция НайтиПохожиеТовары(Название)
    Соединение = Новый HTTPСоединение("localhost", 8080);
    Запрос = Новый HTTPЗапрос("/find");
    Запрос.Заголовки.Вставить("Content-Type", "application/json");
    Тело = "{ ""items"": [ { ""name"": """ + Название + """ } ] }";
    Запрос.УстановитьТелоИзСтроки(Тело);
    Ответ = Соединение.ОтправитьДляОбработки(Запрос);
    Возврат Ответ.ПолучитьТелоКакСтроку();
КонецФункции
```

## FAQ

**Ничего не находит**

- Данные загружены? Проверьте `/health` → `db_record_count`.
- Используете `id` при импорте?

**Не находит с опечатками**

- Увеличьте `fuzzy_max_distance` в `config.toml` (0 — точное, 1 — одна ошибка, 2 — две).

**Находит не те товары**

- Подстройте `auto_match_threshold`.
- Добавьте стоп-слова и синонимы.

**Как искать только по бренду?**

- Передайте `"name": ""` и `"brand": "Bosch"`.

**Почему «болтом» не находит «болт»?**

- По умолчанию `fuzzy_max_distance = 1`. Установите `2` для морфологических форм.
