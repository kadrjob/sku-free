# История изменений

Все значимые изменения SKU Search Free. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.3.1] — 2026-10-15

### Исправлено

- Приведена в порядок документация: актуальные цена PRO-лицензии, порт
  сервиса и контакты поддержки.
- Из инструкций по CLI и API убраны порты, которых нет в поставке. Сервис
  слушает `8080`.

## [0.3.0] — 2026-10-14

Крупное обновление качества поиска и скорости.

### Добавлено

- **Кэш поисковых запросов теперь и в Free.** Раньше он был только в PRO. Повторные запросы обслуживаются из кэша: время ответа падает с 2,23 мс до **0,46 мс** — ускорение в 4,8 раза. Кэш сбрасывается автоматически при загрузке, удалении и очистке данных.
- **Канонический файл стоп-слов в поставке** — `data/stopwords.txt`, 157 русских стоп-слов с поддержкой комментариев через `#`. `setup.sh` и `setup.cmd` копируют его при первичной настройке.
- **Стабильное первое место в ранжировании.** Добавлен параметр `[search.weights].length_penalty_factor` (по умолчанию `0.1`): при равных оценках выше поднимается более короткое название. Это убирает недетерминированность ранжирования Tantivy — теперь top-1 не «прыгает» между одинаковыми запросами.

### Исправлено

- **Recovery точности exact-поиска: recall@1 вырос с 42 % до 64 %.** Причина была в стоп-словах «кг» и «л»: это единицы измерения, которые входят в названия товаров («1 кг», «2,5 л»). Их удаление из запроса лишало поиск различения по размеру, и товар с неверной единицей вытеснял правильный. Убраны из production-файла стоп-слов.
- **Скорость хвоста запросов.** Включён `optimize_on_startup = true`: индекс сводится к одному сегменту, p95 падает с 42 мс до **~2,5 мс**.
- **Пустые строки в запросе больше не ломают поиск.** Запрос вида `{"name": "болт", "code": ""}` раньше возвращал пустой результат, потому что пустая строка попадала в регистрозависимый exact-фильтр. Теперь `""` и строки из пробелов для полей `id`, `code`, `art`, `type`, `ref`, `desc`, `parent_id`, `group_id` трактуются как «поле не задано».
- **Исправлены имена файлов в архиве для Windows.** Расширение для 1С называлось `СКУПоиск.cfe` и записывалось в архив без флага UTF-8. На Linux распаковывалось правильно, а встроенный архиватор Windows показывал кракозябры вместо имени. Архивы теперь собираются так, что флаг выставляется.

### Изменено

- **Ускорена обработка кандидатов в fuzzy-поиске.** Автомат Ахо-Корасик строится один раз на весь запрос и переиспользуется; в последовательном режиме документы читаются из Tantivy один раз вместо двух; exact-сопоставление слов переписано на один проход с `HashSet`. Время ответа: exact с 2,36 до **2,09 мс**, fuzzy с 2,34 до **2,18 мс**. Качество не изменилось.

### Известные особенности

- INT8-модели не работают на GPU в ONNX Runtime (нет CUDA-ядер `MatMulInteger`) — это относится к PRO, но важно знать, если будете экспериментировать.
